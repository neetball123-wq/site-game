# ヨリミチ — 体験型サイト集

（フォルダ名・リポジトリ名は旧名「ウラガワ」のまま）

「ちょっと、寄っていきませんか。」——ブラウザの中の“どこか”（閉館する天文館、明治の娘との文通、昭和の賭場、深夜のオンライン内見……）へ寄り道して、調べて、選んで、ときには戦って、終わりまで見届ける体験型の作品を集めたサイトです。
`index.html` を開くと作品の一覧が出て、選んだ作品をその画面の中で遊べます。

## 作品を追加する手順

1. `works/<作品ID>/` に作品を置く。入口は `index.html`。CSS・JS・画像は相対パスで読み込む。
2. `works.js` の `WORKS` に1件追加する（下のひな形）。
3. 一覧をブラウザで開き、表紙・進行状況・「遊ぶ」を確認する。
4. Xなどにリンクを貼ったとき画像つきで出るように、リンクカードを用意する。
   - 画像：`works/<作品ID>/img/og.jpg`（1200×630）。
   - `index.html` の `<head>` に `og:title`・`og:description`・`og:url`・`og:image`・`twitter:card`（`summary_large_image`）を入れる。`og:url` と `og:image` は `https://neetball123-wq.github.io/site-game/` から始まる絶対URLにする。
   - 画像は手元の `_og/`（git管理外）で作れる。一覧を `python -m http.server 8940` で開いた状態で `node _og/shoot.js <保存先> <作品ID>=id=<作品ID>` を実行すると、`_og/gen.html` の見た目で撮影する。
5. 公開版（Artifact）を更新する場合は、一覧と `works/` 以下のファイルを同じArtifactに再公開する。

```js
{
  id: 'sakuhin',                       // フォルダ名と同じ。英小文字とハイフン
  path: 'works/sakuhin/index.html',
  title: '作品名',
  place: '一覧の「今夜の寄り道先」に出る、その作品の場所のひとこと',
  added: '2026-10-01',                 // 追加日。新しい順に並び、14日間 NEW が付く
  genre: ['ミステリー', '…'],
  minutes: 30,                         // 遊ぶ時間の目安（分）
  difficulty: 3,                       // 難しさ 1〜5
  accent: '#C9502B',                   // カードのボタンと進行バーの色
  catch: 'ネタバレにならない一文の紹介。',
  features: ['見どころ', '…'],
  storageKey: 'sakuhin.v1',            // 作品が localStorage に保存するキー
  progress(s) {                        // 保存データ s → 一覧に出す進み具合
    return { pct: 0, label: '第一章', cleared: false };
  },
  haunt(s) {                           // 任意。作品の中から一覧に干渉したいとき
    return null;                       // 例：{ tagline: '一覧の見出しを差し替える文', mark: '全カードに付く印' }
  },
  spoilers: ['答え1', '答え2'],        // 「答えを見る」に出す内容
  cover: {
    front: '<svg viewBox="0 0 400 250">…表の顔…</svg>',
    back: '<svg viewBox="0 0 400 250">…めくると見える裏側…</svg>'
  }
}
```

## 作品づくりのルール

- **1作品＝1フォルダ**で完結させる。一覧（`hub.js` など）に作品固有の処理を書かない。
- **保存キーは `作品ID.v1`** のように作品ごとに分ける。同じブラウザ・同じ場所で動くので、キーがかぶると記録が混ざる。
- **作品の中に「一覧へ戻る」リンクは置かない。** 戻るのは一覧側の上のバーが担当する（作品の世界観を壊さないため）。
- 作品は単体で開いても動くようにする（「新しいタブで開く」で直接開かれるため）。
- 表紙の SVG の `id`（グラデーションなど）には作品IDの接頭辞をつける（例：`ka-f`）。一覧では全作品の表紙が同じページに並ぶため。
- ボリュームの目安は **約30分**。クリックだけで終わる謎ではなく、ページをまたいだ照合・計算・解読などを組み合わせ、行き詰まったときの段階的なヒントを作中に用意する。
- 作品の中に「本作品はフィクションです」の表記を入れる。
- **作品ごとに見た目も構成も変える。** ヘッダー・メニュー・お知らせの形を他の作品と揃えない。普通のホームページの形でなくてよい（例：写真集＋目次、状差し＋絵はがき、テレビ局＋リモコン）。おしゃれさ・エモさを優先しつつ、読みやすさは保つ。
- **ヒントと答えは、最初は閉じておく。** その段階で考えている時間（画面が見えているあいだだけ数える）が、ヒント1＝2分・ヒント2＝5分・答え＝8分をこえたら一段ずつ開く。まだのときは「あと◯分」と作品の世界の言葉で伝える。
- **保存データに `playMs`（遊んだ時間のミリ秒）を入れる。** 5秒ごとに、画面が見えているときだけ足す。一覧の「答えを見る」は、この時間に応じて上から順に開く（クリアするとすべて）。
- **`minutes`（目安時間）は、実際に遊んだ場合の時間にする。** 盛らない。
- 写真を使う場合は `works/<id>/img/` に置き、ファイルが無いときは絵（SVGなど）に戻る作りにする。

## 手元で動かす

`serve.py`（一つ上のフォルダ）でサーバーを立て、`http://localhost:8931/uragawa/` を開く。
ファイルを直接開く（file://）と、ブラウザによっては作品の記録が一覧に反映されない。
